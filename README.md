# Catch 22 — приглашение-плеер

Статическая страница без сборки. Весь экран — корпус кассетного плеера; приглашение остаётся доступным HTML-текстом на бумажной наклейке. На узких экранах элементы располагаются вертикально, на широких — в две колонки.

## Локальный запуск

```sh
python -m http.server 3000 --bind 0.0.0.0
```

Открыть `http://localhost:3000`. Воспроизведение запускается кнопкой PLAY. REW отматывает на три секунды, STOP останавливает и сбрасывает трек. Громкость меняется перетаскиванием или стрелками при фокусе на ползунке. Настройка reduced motion отключает вращение и бегущую строку.

## Оформление

- `index.html` — текст приглашения, разметка и аудиологика.
- `assets/player.css` — корпус, расположение деталей и адаптивность.
- `IMG_1452.png` — основной визуальный референс и источник потёртых материалов, наклеек и механических деталей.
- `assets/worn/` — оптимизированные WebP-фрагменты референса. Его чужие дата, адрес и название заведения не используются в приглашении.
- `assets/fonts/` — локальные Caveat и Oswald с OFL-лицензиями; обращения к Google Fonts не нужны.

Чтобы пересобрать материалы в Python-окружении с `Pillow`, `numpy` и `opencv-python-headless`:

```sh
python tools/build_reference_assets.py
```

Оригинальные изображения и наклейки сохранены. `gen/` предназначен для временных файлов и исключён из Git.
