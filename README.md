# Catch 22 — приглашение-плеер

Статическая страница без сборки. Интерфейс собран слоями в формате референса
`IMG_1452.png`: сгенерированная панель кассетного плеера, поверх неё —
вращающиеся хабы, сгенерированные клавиши транспорта, крупные фирменные
стикеры из `assets/stickers/` и нижняя инфо-панель с датой и местом.
Текст приглашения живёт в бегущей строке дисплея при нажатии PLAY
и продублирован скрытым блоком для скринридеров.

## Локальный запуск

```sh
python -m http.server 3000 --bind 0.0.0.0
```

Открыть `http://localhost:3000`. Воспроизведение запускается кнопкой PLAY —
в дисплее стартует бегущая строка с текстом приглашения. REW отматывает
на три секунды, STOP останавливает и сбрасывает трек. Громкость меняется
перетаскиванием или стрелками при фокусе на ползунке. Настройка
reduced motion отключает вращение хабов и бегущую строку.

## Оформление

- `index.html` — текст приглашения, разметка слоёв и аудиологика.
- `assets/player.css` — композиция слоёв, позиции стикеров и адаптивность.
- `assets/layers/` — оптимизированные webp-слои устройства:
  `plate.webp` (панель корпуса с динамиком, кассетой и нишами клавиш),
  `reel.webp` (вращаемый хаб), `key-small.webp` / `key-play.webp` (клавиши),
  `body-tex.webp` (потёртая текстура фона страницы).
- `assets/stickers/` — стикеры, вырезанные из листа `IMG_1448.jpeg`;
  раскладываются по панели крупнее, чем в прежних итерациях.
- `assets/fonts/` — локальные Caveat и Oswald с OFL-лицензиями;
  обращения к Google Fonts не нужны.
- `IMG_1452.png` — текущий визуальный референс, по которому сгенерированы слои.
- `IMG_1448.jpeg`, `IMG_1449.jpeg`, `IMG_1453.png` — лист стикеров и
  референсы прежних итераций.

## Генерация слоёв

Слои устройства генерируются отдельно (панель, хаб, клавиши, текстура)
и постобрабатываются скриптом: прозрачность вместо чёрного фона, обрезка,
webp. Геометрия хабов зафиксирована в процентах панели и проверена
отладочными композитами.

```sh
python3 -m pip install --user pillow numpy
python tools/build_layers.py
```

`tools/build_reference_assets.py` и `tools/cut_stickers.py` — скрипты прежних
итераций: вырезание потёртых фрагментов из фото и стикеров из листа.
`gen/` — временные файлы генераций и отладочные композиты, исключён из Git.
